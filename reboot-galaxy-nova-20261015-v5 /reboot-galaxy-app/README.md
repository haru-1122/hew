# Reboot Galaxy NOVA — 設定資料から物語が生まれる銀河（展示版）

前の版（Reboot Galaxy・ガイドオーバーレイ5秒版）の**上位互換**です。
画面・背景・演出をすべて作り直し、サーバーの仕組み（ログイン・同意・分配・返金・プロフィール・月額デモ）は
**同じAPI・同じデータベース**のまま引き継いでいます。

資料の利用開始は0円。完成作品が売れたときだけ、制作者80％・元の設定作者10％・運営10％を記録します。
すべての取引は展示用のデモで、実際のお金は動きません。

## 起動

Node.js 24以上が必要です（データ保存に Node.js 標準の SQLite を使います）。

- Windows：ZIPをすべて展開し、`start-windows.bat` をダブルクリック
- Mac：`start-mac.command` をダブルクリック
- ターミナル：このフォルダで `npm install` → `npm start`

初回だけ、依存パッケージ（デザイン系ライブラリとフォントを含む）の取得にネット接続が必要です。
取得後はオフラインの展示会場でも、同じ書体・同じ演出で動きます（CDNを使いません）。
表示されたURL（通常 http://localhost:3000）を開いてください。HTMLを直接開いても取引処理は動きません。

## 3つの立場で試す（前の版と同じ手順）

ログイン画面の「デモアカウントで試す」から選べます。パスワードは `rebootgalaxy`（展示専用）。

1. **読者・利用者（ao@example.com）**：「物語を読む」で『星を渡る放課後』をデモ購入（500円）
2. **制作者（sora@example.com）**：右上のアイコン →「マイページ」で制作者分 400円 を確認
3. **設定作者（haru@example.com）**：マイページで設定作者分 50円 を確認
4. ao に戻り、マイページの購入履歴から「デモ返金」→ 双方の配分が0円に戻ります
5. 同じ作品は返金前に重複購入できません。返金後の新しい購入は別の取引です

公開の場では `.env` に `RG_HIDE_DEMO=1` と書くと、デモアカウントのボタンを隠せます。

## 画面の動き（標準／控えめ）

はじめは端末の「動きを減らす」設定（Windows の「アニメーション効果」など）に従います。
「控えめ」では、カメラの揺れ・ワープ・大きな移動を止め、星のまたたきや光のゆらぎだけを静かに残します。
画面下の「動き：標準／控えめ」ボタン（ログイン画面・ホーム・案内画面、または設定）で切り替えられ、その端末に保存されます。

重さに応じて背景の解像度を自動で下げ、タブを離れると描画を止めます。
WebGL が使えない環境では平面の星空・静止画の原画に切り替わり、操作はすべてそのまま使えます。

Lenis／Swiper／Chart.js／Tippy.js＋Popper／vanilla-tilt／CountUp.js／canvas-confetti／Lucide／@fontsource の各書体

## データの保全・前の版からの引き継ぎ

テーブル構成は前の版と同じです（rg_sources / rg_agreements / rg_works / rg_sales ほか）。
前の版を停止し、`data` フォルダ全体をバックアップしてから、このフォルダへコピーすればそのまま使えます。
稼働中のDB単体コピーは避けてください。`npm run reset` は保全のため停止します。

デモ作者6人には自己紹介とアイコンを初期登録します。すでに本人が編集したプロフィールは上書きしません。

## 検証

`npm test` で、前の版の取引テスト・加入テストに加えて、次を確認します（インメモリDB・利用中のDBは書き換えません）。

- 公開の集計・最近の動きに、購入者の名前やメールアドレスが出ないこと。返金すると集計から消えること
- 設定（edition・デモアカウント表示）と、表紙画像（利用者の新作は元資料の画像を受け継ぐ）
- デザイン系ライブラリとフォントがすべて入っていて、正しい種類で配信され、配信表の外は見えないこと
