# NOVA のデザインと演出のしくみ

## ファイルの地図

```
server.js              起動前の確認（Node 24・SQLite・部品とライブラリがそろっているか。足りなければ npm ci）
lib/app.js             サーバー本体（認証・画面・圧縮・配信）
lib/vendor.js          デザイン系ライブラリの配信表（node_modules → /vendor/…）
lib/revenue.js         資料・同意・作品・購入・返金・マイページ・銀河・公開集計・最近の動き
lib/community.js       プロフィール・フォロー・ファンクラブ／読み放題のデモ加入
public/css/nova.css    共通デザインシステム（色・書体・ガラスのパネル・ボタン・入力・モーダル・トースト）
public/js/core/
  cosmos.js            宇宙背景エンジン（3画面共通）
  shaders.js           星雲・星・惑星・環・大気・流れ星・仕上げの GLSL
  artwork.js           生きている原画（WebGLで原画に光を流す）
  warp.js              画面移動の光速航行
  ui.js                共通部品（Lenis・GSAP・Tippy・tilt・CountUp・紙吹雪・トースト・モーダル・動きの設定）
public/js/app/
  galaxy3d.js          みんなの銀河（Three.js）
  views.js             4つの画面の描画（マイページはメニューに置かず、右上のアイコンから開く）
  flows.js             資料・同意・購入・作品登録・プロフィール・加入のモーダル
  main.js              起動・画面切り替え・コマンドパレット
public/images/covers/  完成ストーリーの表紙（前の版の6分割画像を、1枚ずつの画像に切り出したもの）
public/images/sources/ 作品のもと（設定資料）の「未完成のラフ」画像
```

## 操作のしかた

**物語を読む（カバーフロー・Swiper）**

| 操作 | 動き |
|---|---|
| ドラッグ・スワイプ | 横に動く。投げると勢いで流れ、止まるときはカードの位置にぴたりと合う（freeMode＋sticky） |
| Shift＋ホイール／トラックパッドの横スクロール | 横に動く。ふつうの縦ホイールはページのスクロールのまま |
| ← → キー、左右の丸いボタン | 1枚ずつ送る |
| 下のバー | つまんで左右に動かせる。左に「03 / 06」の位置表示 |
| 横のカードを押す | 中央に来る。中央のカードを押すと購入確認が開く |
| 自動で送る | 押すと自動送り。自分で動かした時点で止まる |

カード全体がボタンなので、Swiper の既定（ボタンの上ではドラッグしない）を外しています（`focusableElements` から button を除外）。
カバーフローでは横のカードが3Dで奥に下がり、手前の wrapper がクリックを受けてしまうため、wrapper は `pointer-events: none` にしています。

**銀河から探す（Three.js）**

| 操作 | 動き |
|---|---|
| ドラッグ／横になぞる | 回す |
| Ctrl（⌘）＋ホイール、指2本のピンチ | 拡大・縮小。Ctrl なしのホイールはページのスクロールに使い、「Ctrl＋ホイールで拡大」と小さく知らせる |
| 右下のボタン | 左右に回す・近づく・遠ざかる・自動回転の停止/再開・中心にもどす |
| 星の名前（ラベル）を押す | 星を押したのと同じ。小さな星をねらわなくてよい。Tab キーで順に選べる |
| 銀河にフォーカスして ←→↑↓・＋−・0 | 回す・拡大縮小・中心にもどす |

ポインタが銀河の上にある間は自動回転を止め、星が逃げないようにしています。

## 作品のもと＝未完成のラフ、完成ストーリー＝表紙

銀河から探す・作品のもと一覧・資料の詳細・銀河の星の吹き出しでは、完成表紙とは別の
`images/sources/` のラフ画像を使います。表紙の原画から作った鉛筆の下描きに、
塗りかけの下塗り・レイアウト用紙の青い当たり線・赤鉛筆のメモ・配色メモ・「ROUGH／設定資料・未完成」のはんこを重ねたものです。
資料（ラフ）→ 完成作品（表紙）と、同じ場面が仕上がっていく関係が見た目で分かります。
API では資料の `cover.stage` が `draft`、完成作品は `finished` です。利用者が登録した作品は、元資料の完成表紙を受け継ぎます。

## 宇宙背景エンジン（cosmos.js）

1. **星雲**：二段のドメインワープ fbm（simplex noise）で、起動時に一度だけ 2304px の HDR テクスチャへ焼き付けます。
   毎フレームは、カメラの向きから空の座標を計算してテクスチャを敷くだけなので軽く、星と星雲が同じ量だけ視差で動きます。
2. **星**：天の川の帯に集まるように約1万個。色温度（青白〜橙）と明るさの分布、明るい星だけ回折スパイク。
3. **物語の星座**：6つの星座の線が、のびて、つながり、消えていく（資料がつながって物語になる、の比喩）。
4. **惑星**：緯度の縞＋乱流、嵐の渦、極のかすみ、昼夜の境目の散乱光、大気の縁の光（裏面の殻）、環（リング上の点から太陽方向の光線で惑星の影）、惑星に落ちる環の影、衛星。
5. **遠い渦巻銀河**・**流れ星**・**手前の塵**（ワープで光条になる）。
6. **仕上げ**：UnrealBloom → 色収差・周辺減光・フィルム粒子・フラッシュ → ACES トーンマッピング。

フレーム時間を見て解像度を 0.6〜1.35 倍の間で自動調整します。みんなの銀河が画面に見えている間は背景を 30fps に落とします。

## 画面ごとのプリセット

- `login`：右に環のある惑星、明るい星雲、星座
- `welcome`：遠くに赤い小惑星、原画を主役にするため星雲は控えめ
- `app`：文字を読む画面なので暗め。画面ごとに星雲の明るさを変える（銀河 < 物語 < 出品・マイページ）
