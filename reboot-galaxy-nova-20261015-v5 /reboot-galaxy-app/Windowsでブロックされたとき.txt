Reboot Galaxy ― Windows で「危険なためブロックしました」と出るときの対処
================================================================

■ 何が起きているのか

インターネットからダウンロードしたファイルには、Windows が
「外から来たファイル」という目印を付けます。

start-windows.bat のように自動で命令を実行できる種類のファイルに
この目印が付いていると、Windows の SmartScreen が念のため実行を止めます。

ファイルの中身が悪いわけではありません。
中身は「node があるか確かめて、npm install と npm start を実行する」
だけの、10行ほどの内容です（メモ帳で開けば読めます）。中を見ても
怪しい命令（外部への通信や、隠しコマンドなど）は入っていません。

この警告は、Windows が「インターネットからダウンロードした
実行系ファイル（.bat・.exe など）」に自動でつける目印（Mark of the Web）
と、それに対する SmartScreen の仕組みによるものです。
ファイルの中身を書き換えても、この目印自体は消せません
（目印は、ダウンロードした時点で Windows 側が付けるものだからです）。
そのため、いちばん確実なのは対処0（.bat を使わずに起動する）です。

対処は4つあります。上から順に試してください。


----------------------------------------------------------------
■ 対処0（いちばん確実・おすすめ）
   .bat を使わず、コマンドを自分で打って起動する
----------------------------------------------------------------

ターミナルに自分でコマンドを打つ場合は、この警告はそもそも出ません。

  1. 展開したフォルダ（server.js がある場所）を開く
  2. 画面の上にある白い帯（フォルダの場所が出ているところ）をクリックして、
     文字をすべて消し、次を入力して Enter キー

         powershell

  3. 黒い画面（または青い画面）が開くので、次を1行ずつ入力して Enter

         npm install
         npm start

     ※ npm install は初回だけです。2回目からは npm start だけで起動します。

  4. 「Reboot Galaxy NOVA が起動しました」と出たら、
     ブラウザで次を開く

         http://localhost:3000

  5. 終わるときは、その黒い画面で Ctrl キーを押しながら C

  それでも .bat のダブルクリックで起動したい場合は、対処1〜3を試してください。


----------------------------------------------------------------
■ 対処1
   ZIP の目印を消してから展開する
----------------------------------------------------------------

展開する前の ZIP ファイルに対して行うのがコツです。
ここで消しておくと、中のファイル全部から目印が消えます。

  1. ダウンロードした reboot-galaxy-app.zip を右クリック
  2. 「プロパティ」を選ぶ
  3. いちばん下に
       セキュリティ: このファイルは他のコンピューターから取得したものです。
     と出ていたら、その右にある「許可する」にチェックを入れる
  4. 「OK」を押す
  5. そのあとで ZIP を展開する
  6. start-windows.bat をダブルクリック

※ すでに展開してしまった場合は、
   start-windows.bat を右クリック →「プロパティ」→「許可する」にチェック → OK
   でも同じ効果があります。

※ フォルダの中のファイルをまとめて解除したい場合は、対処0の 1〜2 の手順で
   PowerShell を開き、次を1行だけ入力して Enter しても同じ効果があります。

       Get-ChildItem -Recurse | Unblock-File


----------------------------------------------------------------
■ 対処2　青い画面から実行する
----------------------------------------------------------------

「Windows によって PC が保護されました」という青い画面が出た場合は、

  1. 「詳細情報」を押す
  2. 下に出てくる「実行」を押す

これで起動します。


----------------------------------------------------------------
■ 対処3　bat を自分で作り直す
----------------------------------------------------------------

自分のパソコンの中で作ったファイルには、「外から来た目印」が付きません。
メモ帳で保存し直すだけで、同じ内容の新しいファイルが作れます。

  1. start-windows.bat を右クリック →「その他のオプションを表示」
     →「編集」（または「プログラムから開く」→「メモ帳」）
  2. メモ帳が開いたら、「ファイル」→「名前を付けて保存」
  3. 保存画面で次のように指定する

         ファイルの種類 : すべてのファイル (*.*)
         ファイル名     : start2.bat
         文字コード     : ANSI

     ※ 保存先は、いまのフォルダ（server.js があるところ）のままにしてください。
  4. できあがった start2.bat をダブルクリック


----------------------------------------------------------------
■ それでも動かないとき
----------------------------------------------------------------

・「Node.js が見つかりません」と出る
    https://nodejs.org/ から LTS版（v24 以上）を入れてください。

・「Node.js のバージョンが古い」と出る
    同じく https://nodejs.org/ から入れ直してください。
    このアプリには v24 以上が必要です。

・以前の版から入れ替えた場合で、npm install がエラーになる
    フォルダの中の
        node_modules      （フォルダ）
        package-lock.json （ファイル）
    の2つを消してから、もう一度やり直してください。
    data フォルダは消さないでください（アカウントと出品が入っています）。
